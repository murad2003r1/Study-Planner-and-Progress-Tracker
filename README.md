# স্টাডি প্ল্যানার ও প্রোগ্রেস ট্র্যাকার (Study Planner & Progress Tracker)

এটি একটি পাইথন দিয়ে তৈরি কমান্ড-লাইন (CLI) অ্যাপ্লিকেশন, যা দিয়ে আপনি সহজেই আপনার পড়াশোনার পরিকল্পনা করতে পারবেন এবং নিজের অগ্রগতি ট্র্যাক করতে পারবেন।

## বৈশিষ্ট্য (Features)

- 📚 **বিষয় ও টপিক যোগ করুন** — যেকোনো সাবজেক্টের অধীনে টপিক সাজিয়ে রাখুন
- ⏱️ **স্টাডি সেশন লগ করুন** — প্রতিটি টপিকে কত ঘণ্টা পড়াশোনা করেছেন তা নোট সহ সংরক্ষণ করুন
- 📊 **প্রোগ্রেস বার** — প্রতিটি বিষয় এবং সামগ্রিক অগ্রগতি শতাংশ আকারে দেখুন
- 📅 **ডেডলাইন ট্র্যাকিং** — প্রতিটি টপিকের জন্য নির্দিষ্ট সময়সীমা সেট করুন এবং কোনটি বাকি বা মেয়াদ উত্তীর্ণ তা দেখুন
- ✅ **সম্পন্ন/অসম্পন্ন চিহ্নিতকরণ** — যেকোনো সময় টপিকের অবস্থা পরিবর্তন করুন
- 🗑️ **বিষয় মুছে ফেলা** — নিশ্চিতকরণসহ যেকোনো বিষয় ডিলিট করার সুযোগ

## প্রয়োজনীয়তা (Requirements)

- Python 3.6 বা তার উপরের ভার্সন
- কোনো অতিরিক্ত লাইব্রেরি ইনস্টল করার দরকার নেই (শুধু পাইথনের বিল্ট-ইন লাইব্রেরি ব্যবহার করা হয়েছে)

## কীভাবে চালাবেন (How to Run)

টার্মিনাল বা কমান্ড প্রম্পটে নিচের কমান্ডটি লিখুন:

```bash
python study_planner.py
```

চালু হলে একটি মেনু দেখতে পাবেন, যেখান থেকে সংখ্যা টাইপ করে অপশন বেছে নিতে পারবেন।

## মেনু অপশনসমূহ

| নম্বর | অপশন |
|------|------|
| ১ | নতুন বিষয় (Subject) যোগ করুন |
| ২ | কোনো বিষয়ে টপিক যোগ করুন |
| ৩ | স্টাডি সেশন লগ করুন |
| ৪ | টপিক সম্পন্ন/অসম্পন্ন চিহ্নিত করুন |
| ৫ | প্রোগ্রেস রিপোর্ট দেখুন |
| ৬ | আসন্ন ডেডলাইনগুলো দেখুন |
| ৭ | কোনো বিষয় মুছে ফেলুন |
| ০ | প্রোগ্রাম থেকে বের হন |

## ডেটা কোথায় সংরক্ষণ হয়

আপনার সব তথ্য (বিষয়, টপিক, সেশন, ডেডলাইন) স্বয়ংক্রিয়ভাবে `study_data.json` নামক ফাইলে সংরক্ষিত হয়, যা `study_planner.py` ফাইলের মতো একই ফোল্ডারে তৈরি হয়। ফলে প্রোগ্রাম বন্ধ করে আবার চালু করলেও আগের সব ডেটা থেকে যাবে।

## উদাহরণ ব্যবহার (Example Workflow)

1. প্রথমে **অপশন ১** দিয়ে একটি বিষয় যোগ করুন, যেমন "গণিত"
2. তারপর **অপশন ২** দিয়ে সেই বিষয়ে টপিক যোগ করুন, যেমন "ত্রিকোণমিতি" (ডেডলাইনসহ)
3. পড়াশোনা শেষে **অপশন ৩** দিয়ে কত ঘণ্টা পড়েছেন তা লগ করুন
4. টপিক শেষ হলে **অপশন ৪** দিয়ে সেটি "সম্পন্ন" হিসেবে চিহ্নিত করুন
5. যেকোনো সময় **অপশন ৫** দিয়ে আপনার সামগ্রিক অগ্রগতি দেখুন
